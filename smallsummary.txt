JOBIE PROJECT SUMMARY
=====================

WHAT IT IS
----------

Jobie monitors public LinkedIn guest job results and tracks opportunities for
human review. Persistent state is stored in Supabase PostgreSQL using the
`SUPABASE_DB_URL` connection string. Telegram sends notifications; the user
reviews listings and applies manually.

SAFETY BOUNDARY
---------------

The workers do not log in to LinkedIn, use cookies or credentials, bypass
controls, fill forms, or submit applications. The public endpoint is not an
official API and may be incomplete or unavailable. Respect source terms,
rate limits, and permissions.

TWO WORKERS
-----------

1. Main search/API worker: `app.linkedin_fresh_jobs:app` searches the configured
   lookback window, deduplicates in PostgreSQL, serves health/search/digest
   endpoints, and sends scheduled or manual digests.
2. Ultra-fresh watcher: `python -m app.fresh_watcher` checks the last two
   minutes by default and sends immediate Telegram alerts. It is a separate
   process and can use `FRESH_WATCHER_BOT_TOKEN` and `FRESH_WATCHER_CHAT_ID`.

The separate import API (`app.main:app`) accepts authenticated manual or
authorized-feed records.

GETTING STARTED ON WINDOWS
--------------------------

    python -m venv .venv
    .venv\Scripts\python.exe -m pip install -r requirements.txt
    Copy-Item .env.example .env
    notepad .env

Set `SUPABASE_DB_URL`, a strong `JOBIE_API_TOKEN`, Telegram credentials, and
search keywords/location. Then run the two workers in separate terminals:

    .venv\Scripts\python.exe -m uvicorn app.linkedin_fresh_jobs:app --host 127.0.0.1 --port 8000
    .venv\Scripts\python.exe -m app.fresh_watcher

The main worker health URL is `http://127.0.0.1:8000/health`. The import API
can run separately on port 8001:

    .venv\Scripts\python.exe -m uvicorn app.main:app --host 127.0.0.1 --port 8001

RENDER START COMMANDS
---------------------

    python -m uvicorn app.linkedin_fresh_jobs:app --host 0.0.0.0 --port $PORT
    python -m app.fresh_watcher

Create two Render Background Worker services and configure `SUPABASE_DB_URL`
and the required secrets in each service.
